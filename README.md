# cka-boutique-bougies
Le plus gros site que j'ai pu faire à ce jour.
CKA est un site e-commerce de bougies artisanales, réalisé en HTML, CSS et JavaScript sans framework. 
Le visiteur peut parcourir six produits avec filtres et recherche, remplir un panier avec gestion du stock, voir ses frais de livraison calculés selon le poids (offerts dès 50 €), puis payer avec PayPal, la commande étant ensuite envoyée par email grâce à EmailJS. 
Le site est responsive et hébergé sur Netlify : https://thecka.netlify.app/. Pour le lancer en local, il suffit d'ouvrir index.html dans un navigateur. Comme tout fonctionne côté navigateur, les prix et le stock ne sont pas vérifiés par un serveur, ce que je ferais dans une version plus sérieuse, avec un back-end et une base de données.
